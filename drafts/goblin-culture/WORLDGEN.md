# Goblin camp: world-gen hookup (design, not yet booted)

Status 2026-11-05: data generated, flat-ground assembly simulated, **nothing loaded in game yet**.

## What ships
`data/isekai_wilds/` in this folder is a complete datapack tree, generated by `python -m tools.culturegen`:

| file | what |
|---|---|
| `structure/goblin/*.nbt` | 8 pieces (hut, chief hall, watchtower, work shed, fire circle, 3 paths), DataVersion 3955 |
| `worldgen/template_pool/goblin/{center,chief,streets,houses}.json` | pools; paths are `terrain_matching`, buildings `rigid` |
| `worldgen/structure/goblin_camp.json` | jigsaw structure, start pool `center`, depth 5, radius 64, `beard_thin` |
| `worldgen/structure_set/goblin_camp.json` | random_spread, spacing 40 / separation 16 chunks |
| `tags/worldgen/biome/has_structure/goblin_camp.json` | `#minecraft:is_forest`, `#minecraft:is_taiga` |

Home: **`isekai_wilds`** (our world-content jar), copied into `isekai_wilds_build/staging/data/`. Data only, no Java.
The spec's `modid` sets the namespace, so moving it is one line and a rerun.

## Layout (jigsaw connectors)
fire circle (start) --N/E/W--> paths --ahead--> more paths; path sides --> houses pool (hut 6, shed 3, tower 1);
fire circle --S--> chief's hall (always one, door facing the fire). Connector names: `street`, `street_exit`,
`street_side`, `building_entrance`, `hall_entrance`. The generator checks every connector statically
(a pool exists and holds a piece with the matching name) and fails the run if not.

`goblin_village_seed{1,2}.png` are flat-ground simulations of the assembly (16 and 22 pieces). The game's own
generator follows terrain and priorities, so real camps will differ in detail.

## Open checks (need the Tensura jar or a boot)
1. **Tensura's own `tensura:goblin_village`** is the only natural source of goblins (structure-only spawning,
   docs/kingdom/build-signatures.md). Read its structure json in the jar: if goblins come from its
   `spawn_overrides`, either copy them into ours, or (recommended) override `data/tensura/worldgen/structure/
   goblin_village.json` to use our `center` pool so every Tensura goblin village gets our look and keeps its spawns.
   Also check whether isekai_kingdoms conquest keys on that structure id.
2. Tensura Jura biome ids, to add to the biome tag.
3. Banner pattern NBT (`patterns: [{pattern, color}]`) and skull `rotation` 8 = facing north: format from memory.
